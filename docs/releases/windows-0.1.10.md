# Scan My Disk for Windows 0.1.10

Released October 18, 2026.

## Added
- Automatic update checks at startup with Update now, Update in background and Later choices.
- Verified background downloads with progress, ready-to-install notifications and recovery of completed downloads after restarting the app.
- Release notes history and a one-time What's new view after an upgrade.

## Improved
- Automatic and manual checks share one updater and download.
- Installation waits for active tasks and staged cleanup items to be resolved, then verifies the installer again before launching.
- Existing licenses and saved scans are retained.

## Fixed
- The update download deadline now covers the complete streamed response.

Windows 10/11 x64. Users choose when to install. Windows notifications depend on system settings. This installer is not Authenticode signed, so Windows SmartScreen may show an unknown-publisher warning.
