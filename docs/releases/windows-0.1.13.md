# Scan My Disk for Windows 0.1.13

Released November 23, 2026.

## Added
- **Persistent Cleanup Profiles**: Preset routines tailored for Software Developers (node_modules, bin/obj, package caches, Android/Gradle), Video Editors (DaVinci/Premiere render caches, untouched footage), and General PC maintenance.
- **Custom Profile Builder**: Create, edit, and persist custom scan profiles with granular target categories, age/size thresholds, and custom exclusion paths.

## Improved
- **1-Click Batch Staging**: Evaluate matching files across selected folders and stage everything safely into the Cleanup Queue with one click.
- **Safety Guarantee**: Zero hard deletions. All file cleanups strictly route through the Windows Recycle Bin with re-verification and confirmation.

## Fixed
- Temporary file analyzer pattern matching enhanced to catch `.tmp` and `.chk` crash artifacts reliably.

Existing licenses and saved profiles are retained. Windows 10/11 x64.
