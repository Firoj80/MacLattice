# Scan My Disk for Windows 0.1.11

Released October 19, 2026.

## Added
- Dedicated **Temp, cache & logs** screen: find eligible files, select the files to review and confirm before sending them to Recycle Bin.

## Improved
- Cleaner sidebar with **Disk storage** and **More tools** removed from view.
- **Automatic cleanup** focuses on schedule, rules, preview and history.
- All ten sidebar destinations and Settings actions verified against their intended features.

## Fixed
- Temp, cache & logs opens manual review instead of scheduling settings.
- Manual cleanup does not change the automatic cleanup schedule or its last-run timestamp.
- Repeated Build & dependency files clicks reuse the existing window.

Existing licenses and saved scans are retained. Windows 10/11 x64. Cleanup uses Recycle Bin with confirmation and rechecks; recycling alone does not immediately free disk space.

The installer is not Authenticode signed; Windows SmartScreen may show an unknown-publisher warning.
