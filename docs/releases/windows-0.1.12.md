# Scan My Disk for Windows 0.1.12

Released November 21, 2026.

## Added
- **Scan for Free**: Complete disk scanning, folder size visualizer, and cleanup recommendations are now available without entering a license key.
- **In-App License Unlock**: Direct prompt to enter or purchase a license key only when you choose to commit a cleanup or recycle files.

## Improved
- **Non-blocking startup**: You can launch and test the app immediately after installation without being gated behind a license screen.
- Header status pill shows **Free Scanner · Unlock Clean** when unlicensed.

## Fixed
- Clarified SmartScreen download and launch guidance.

Existing licenses and saved scans are retained. Windows 10/11 x64. Cleanup uses Recycle Bin with confirmation and rechecks; recycling alone does not immediately free disk space.

The installer is not Authenticode signed; Windows SmartScreen may show an unknown-publisher warning.
