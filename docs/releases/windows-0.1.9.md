# Scan My Disk for Windows 0.1.9

- New grouped dark sidebar: Overview, Cleanup, Your files and Tools, with colored icons, selected navigation and live cleanup queue count. Scan full PC, Scan Home and Choose Folder stay at the top; Settings stays at the bottom.
- Overview returns to the full scanned tree. Shortcuts open cleanup suggestions, temp/cache/log cleanup settings, build/dependency file review, large/old files, duplicates, applications and image optimization. Disk storage and map filters remain available in collapsible sections.
- New image optimization for JPEG and PNG, with before/after previews and measured size comparison. JPEG quality presets: 75, 85 and 92; PNG re-encoding is lossless. Dimensions, orientation and supported metadata are retained, including location metadata when present.
- Export up to 100 selected images as uniquely named optimized copies. Originals and existing files are never overwritten or deleted. Images without a size benefit are skipped. Export uses additional disk space; keeping originals does not reclaim space.
- Dark image/folder selection and output-folder dialogs. Unsupported, animated, oversized, linked/cloud-placeholder and unreadable images are skipped or rejected with an explanation. Work is sequential and cancelable between codec operations.
- Existing deletion-risk guidance, ranked suggestions, optional temp/cache/log cleanup schedules, history, license activation and saved scans are retained. Broad categories are not labelled safe to delete.

Image optimization is manual and is not part of automatic cleanup. The performance boost roadmap is documentation for future work; performance phases have not been implemented in this release.
