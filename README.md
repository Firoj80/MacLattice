# MacLattice

Free Mac storage analyzer. Visualize disk usage with an interactive treemap.

Site: [maclattice.com](https://maclattice.com)

## Pages

- Home, pricing, blog, contact
- Privacy, terms, refund policy
- 16 Mac storage guides

## Develop

```bash
npm install
./startup.sh
```

Requires Node.js 22+.
